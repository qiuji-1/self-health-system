## 5.2 用户认证模块实现

### 5.2.1 登录功能的实现

登录功能采用JWT（JSON Web Token）实现无状态身份认证。用户提交账号和密码后，前端进行双重MD5加密传输，后端验证并签发Token。

#### 登录流程

```
┌─────────────┐      ┌──────────────────┐      ┌─────────────┐
│   用户输入    │      │   后端验证处理     │      │   返回结果   │
│ 账号+密码    │─────▶│ 1.查询用户信息    │─────▶│ JWT Token  │
└─────────────┘      │ 2.BCrypt比对密码  │      │ + 角色(role) │
                     │ 3.生成JWT签发    │      └──────┬──────┘
                     └──────────────────┘             │
                                                     ▼
                                             ┌───────────────┐
                                             │ 根据角色跳转:   │
                                             │ role=1 → 管理员 │
                                             │ role=2 → 普通用户│
                                             └───────────────┘
```

**图5-1  用户登录流程图**

#### 核心代码

**前端登录方法（Login.vue）：**

```javascript
// Login.vue - 登录核心逻辑
async login() {
  if (!this.account || !this.password) {
    this.$message.info('账号与密码不能为空哦');
    return;
  }
  const bcryptPassword = this.$md5(this.$md5(this.password));
  const userLoginDto = { account: this.account, password: bcryptPassword };
  try {
    const { data, message } = await this.$axios.post(`user/login`, userLoginDto);
    setToken(data.token);
    setRole(data.role);
    if (data.role === 1) {
      this.$router.push('/admin');
    } else if (data.role === 2) {
      this.$router.push('/user');
    }
  } catch (error) {
    console.error('登录异常:', error);
    this.$message.error(error.message);
  }
}
```

**后端登录接口（UserController.java）：**

```java
@RestController
@RequestMapping("/user")
public class UserController {

    @Resource
    private UserService userService;

    /** 用户登录 */
    @PostMapping(value = "/login")
    @ResponseBody
    public Result<Object> login(@RequestBody UserLoginDto userLoginDTO) {
        return userService.login(userLoginDTO);
    }
}
```

#### 实现说明

- **安全性**：前端双重MD5加密传输 + 后端BCrypt哈希存储
- **无状态认证**：JWT机制，服务端不存储会话信息
- **角色路由**：role=1为管理员跳转/admin，role=2为普通用户跳转/user

#### 核心代码

```javascript
// router/index.js - Vue Router 全局前置守卫
router.beforeEach((to, from, next) => {
  // 放行登录页和注册页
  if (to.path === '/login' || to.path === '/register') {
    return next();
  }
  // 检查需要认证的路由
  if (to.matched.some(record => record.meta.requireAuth)) {
    const token = getToken();
    if (!token) {
      return next({ path: '/login', query: { redirect: to.fullPath } });
    }
    try {
      const role = parseInt(getRole());
      if (to.matched[0].path === '/admin' && role !== 1) {
        clearToken();
        return next("/login");
      }
      if (to.matched[0].path === '/user' && role !== 2) {
        clearToken();
        return next("/login");
      }
      return next();
    } catch (error) {
      console.error('权限检查失败:', error);
      return next('/login');
    }
  }
  next();
});
```

系统通过**前端路由守卫 + 后端JWT拦截器**实现双重权限控制，防止未授权访问和越权操作。

### 5.3.2 协同过滤推荐算法的实现 ⭐

本系统的资讯推荐基于**协同过滤推荐算法**，根据用户的浏览、收藏、点赞等隐式反馈行为计算偏好，实现个性化内容推荐。

#### 算法流程

```
┌──────────────┐    ┌──────────────────────┐    ┌────────────────┐
│  用户行为采集  │───▶│ 构建用户-物品评分矩阵   │───▶│ 计算相似度矩阵  │
│ (浏览=1 收藏=3  │    │ 按行为类型加权求和    │    │ 余弦相似度公式   │
│  点赞=2)       │    └──────────────────────┘    └───────┬────────┘
└──────────────┘                                        ▼
                                              ┌────────────────┐
                                              │ 生成Top-N推荐  │
                                              │ 按预测评分降序  │
                                              └────────────────┘
```

**图5-5  协同过滤推荐算法流程图**

#### 行为权重设计

| 行为类型 | 权重值 | 含义 |
|---------|:-----:|------|
| 浏览详情 | 1 | FlowIndex记录 |
| 加入收藏 | 3 | 权重最高 |
| 点赞互动 | 2 | Evaluations记录 |

#### 核心算法伪代码

```java
// 协同过滤推荐核心逻辑
public List<HealthNewsListVO> recommend(Integer count) {
    Integer userId = getCurrentUserId();
    // 1. 加权计算用户偏好得分（浏览×1 + 收藏×3 + 点赞×2）
    Map<Integer, Double> preference = calcUserPreference(userId);
    // 2. 找到相似邻居用户（余弦相似度）
    List<Integer> neighbors = findSimilarUsers(userId);
    // 3. 统计邻居喜欢但目标用户未看过的内容
    Map<Integer, Double> scores = new HashMap<>();
    for (Integer nid : neighbors)
        for (FlowIndex action : getActions(nid))
            if (!preference.containsKey(action.contentId))
                scores.merge(action.contentId,
                    similarity(userId, nid) * weight(action.type), Double::sum);
    // 4. 取Top-N返回
    return scores.entrySet().stream()
        .sorted(Map.Entry.<Integer,Double>comparingByValue().reversed())
        .limit(count).map(e -> findById(e.getKey())).collect(toList());
}
```

- **冷启动处理**：新用户退化为热门内容推荐策略

## 5.6 敏感词过滤算法（Trie字典树）⭐⭐

### 5.6.1 Trie字典树结构

采用**前缀树（Trie）**数据结构实现高效敏感词过滤，时间复杂度O(k)，k为文本长度，与敏感词数量无关。

```
                        ┌── root(根节点) ──┐
                        │                  │
                        ▼                  ▼
```

**Trie字典树过滤器核心伪代码：**

```java
public class SensitiveWordFilter {
    private static class TrieNode {
        Map<Character, TrieNode> children = new HashMap<>();
        boolean isEndOfWord;  // 敏感词结尾标记
    }

    // 初始化：构建Trie树
    public void init(List<String> words) {
        for (String word : words) {
            TrieNode node = root;
            for (char c : word.toCharArray()) {
                node.children.putIfAbsent(c, new TrieNode());
                node = node.children.get(c);
            }
            node.isEndOfWord = true;
        }
    }

    // 过滤：敏感词替换为***
    public String filter(String text) {
        StringBuilder result = new StringBuilder();
        for (int i = 0; i < text.length(); ) {
            TrieNode current = root;
            int j = i;
            while (j < text.length() && current.children.containsKey(text.charAt(j))) {
                current = current.children.get(text.charAt(j++));
                if (current.isEndOfWord) { result.append("***"); i = j; break; }
            }
            if (!current.isEndOfWord) result.append(text.charAt(i++));
        }
        return result.toString();
    }
}
```

| 场景 | 处理方式 |
|-----|---------|
| 发表评论时 | 后端先filter()，含敏感词则返回错误提示 |
| 管理审核时 | 展示原始内容和过滤状态，支持手动屏蔽 |
