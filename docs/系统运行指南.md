## 🔧 如何使用系统进行截图

### 步骤1：检查服务状态

在项目根目录运行：
```bash

```

### 步骤2：访问系统

- 打开浏览器，访问: `http://localhost:8080`

1. 点击"注册"，填写信息创建账号
2. 使用注册的账号登录系统

### 步骤4：按清单截图

按照上面的清单，逐页访问并截图：
- 使用 `Win + Shift + S` 进行截图
- 保存为PNG格式，命名规范: `章节_模块_序号.png`
  - 例如: `第5章_用户模块_01_注册页.png`

1. 使用管理员账号登录后台
   - 默认管理员账号: 需要查看数据库或配置文件

## ❓ 常见问题

### Q1: 前端或后端启动失败？
A:
- 检查Java、Maven、Node.js版本是否正确
- 检查端口是否被占用
- 查看启动窗口中的错误信息

### Q2: 无法连接数据库？
A:
- 确认MySQL服务已启动
- 检查配置文件中的数据库连接信息
- 确认数据库`healthsystem`存在

### Q3: 前端页面无法访问？
A:
- 确认前端服务已启动
- 检查浏览器控制台是否有错误
- 确认后端API是否正常

### Q4: 如何停止服务？
A:
- 关闭启动的两个PowerShell窗口即可
- 或者在窗口中按 `Ctrl + C`
